# 💰 API RESTful de Cotação de Moedas (Flask Microservice)

Este projeto é uma API RESTful simples desenvolvida em **Python** com o microframework **Flask**, que consomem dados de fontes externas e os formatam em JSON.

---

## ✨ Destaques do Projeto

* **Tecnologia:** Python 3.x e Flask.
* **Arquitetura:** Microservice (baseado em Flask Blueprint)
* **Funcionalidade:** **Consulta Dinâmica** de cotações para qualquer par de moedas (ex: USD-BRL, BTC-EUR).
* **Interoperabilidade:** Resposta padronizada em formato **JSON**.
